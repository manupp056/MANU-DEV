# MANU.DEV — Web v0.1

Aplicación estática de MANU.DEV construida con Astro y Starlight. La interfaz contiene las secciones Inicio, Formación, Entregas y Evolución, con una estética oscura y estados vacíos mientras no existan fichas verificadas.

Consulta [COMO_EJECUTAR.md](./COMO_EJECUTAR.md) para ejecutar la web en local e incorporar actividades desde `contenido/actividades/`.

## Comandos

```powershell
npm install
npm run dev
npm run build
npm run preview
```

La configuración de GitHub Pages está preparada en `.github/workflows/deploy-pages.yml.example` y no se activa automáticamente.
