## Documentos académicos

Esta sección enlazará las entregas documentadas en las fichas de actividades. Se conservarán los nombres y las versiones exigidas por el profesor, como `_v01` o `_v02`.

### No hay documentos publicados

No consta ninguna entrega disponible para consulta pública. Los archivos de `curso/` permanecen separados de la web y no se copian automáticamente.

Si una entrega no puede redistribuirse, la web podrá documentar su existencia sin exponer el archivo.
